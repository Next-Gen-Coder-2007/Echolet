# Echolet Frontend

The client-side single-page application for **Echolet**, built with React 19, TypeScript, Vite 8, and Tailwind CSS v4.

For the full platform documentation, architecture diagrams, API specs, and setup instructions, please refer to the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Key Technologies

- **React 19** with TypeScript
- **Vite 8** for fast build times and Hot Module Replacement
- **Tailwind CSS v4** with custom animations
- **React Router 7** for declarative nested routing
- **Socket.io Client** for real-time WebSocket events
- **Native WebRTC & Web Audio API** for real-time P2P voice calling, frequency visualizers, and wave playback
- **Lenis** for smooth kinetic scrolling
- **React Icons** & **Lucide** for iconography
